# cf-cdn-tf-shared-policies

Generates `cloudflare-to-aws-cdn/terraform/shared/policies.tf` from the
deduplicated policy manifest. This file must be written **before** any domain
`main.tf` is generated, because domain modules reference these policy resources
by Terraform ID.

### Step 1 — Parse `dedup_manifest.json`

The manifest has this top-level structure:

```jsonc
{
  "cache_policies": {
    "<hash>": {
      "min_ttl": 0,
      "default_ttl": 300,
      "max_ttl": 3600,
      "bypass": false,
      "cookies": { "behavior": "whitelist", "items": ["session"] },
      "headers":  { "behavior": "none",  "items": [] },
      "query_strings": { "behavior": "none", "items": [] },
      "compress": true
    },
    ...
  },
  "origin_request_policies": {
    "<hash>": {
      "cookies":  { "behavior": "all" | "none" | "whitelist", "items": [] },
      "headers":  { "behavior": "allViewer" | "none" | "whitelist", "items": [] },
      "query_strings": { "behavior": "all" | "none" | "whitelist", "items": [] }
    },
    ...
  },
  "response_headers_policies": {
    "<hash>": {
      "cors_config": { ... } | null,
      "security_headers": { ... } | null,
      "custom_headers": [ { "header": "X-Foo", "value": "bar", "override": true } ],
      "remove_headers": [ "X-Powered-By" ],
      "server_timing_headers_config": null | { "enabled": true, "sampling_rate": 0 }
    },
    ...
  }
}
```

Collect all three maps. If a map is absent or empty, skip its section silently.

### Step 3 — Generate `aws_cloudfront_cache_policy` resources

For each entry `<hash>` in `cache_policies`:

**3a. Bypass policy** (`bypass: true` OR `default_ttl == 0 AND max_ttl == 0`):

```hcl
resource "aws_cloudfront_cache_policy" "policy_bypass_<hash>" {
  name        = "cfcdn-cache-bypass-<hash>"
  min_ttl     = 0
  default_ttl = 0
  max_ttl     = 0

  parameters_in_cache_key_and_forwarded_to_origin {
    cookies_config {
      cookie_behavior = "none"
    }
    headers_config {
      header_behavior = "none"
    }
    query_strings_config {
      query_string_behavior = "none"
    }
  }
}
```

**3b. Normal cache policy** (`bypass: false`):

```hcl
resource "aws_cloudfront_cache_policy" "policy_<hash>" {
  name        = "cfcdn-cache-policy-<hash>"
  min_ttl     = <min_ttl>
  default_ttl = <default_ttl>
  max_ttl     = <max_ttl>

  parameters_in_cache_key_and_forwarded_to_origin {
    cookies_config {
      cookie_behavior = "<behavior>"
      # Only include the `cookies` block when behavior == "whitelist" AND items is non-empty
      cookies {
        items = [<quoted, comma-separated items>]
      }
    }
    headers_config {
      header_behavior = "<behavior>"
      # Only include the `headers` block when behavior == "whitelist" AND items is non-empty
      headers {
        items = [<quoted, comma-separated items>]
      }
    }
    query_strings_config {
      query_string_behavior = "<behavior>"
      # Only include the `query_strings` block when behavior == "whitelist" AND items is non-empty
      query_strings {
        items = [<quoted, comma-separated items>]
      }
    }
    enable_accept_encode_brotli = <true|false>   # from compress field; default true
    enable_accept_encode_gzip   = <true|false>   # from compress field; default true
  }
}
```

**Behavior mapping** (Cloudflare → AWS):

| Cloudflare behavior | AWS cookie_behavior / header_behavior / query_string_behavior |
|---|---|
| `none` | `"none"` |
| `whitelist` | `"whitelist"` |
| `all` | `"all"` |
| `allExcept` | `"allExcept"` |
| _(unrecognized)_ | `"none"` and emit a `# WARNING: unrecognized behavior` comment |

**Item list formatting**: always emit as a Terraform list literal with double-quoted
strings, sorted lexicographically. Example: `items = ["foo", "bar", "baz"]` →
after sort: `items = ["bar", "baz", "foo"]`.

### Step 4 — Generate `aws_cloudfront_origin_request_policy` resources

For each entry `<hash>` in `origin_request_policies`:

```hcl
resource "aws_cloudfront_origin_request_policy" "policy_<hash>" {
  name = "cfcdn-orp-<hash>"

  cookies_config {
    cookie_behavior = "<behavior>"
    # Include cookies block only when behavior == "whitelist" AND items non-empty
    cookies {
      items = [<sorted quoted list>]
    }
  }

  headers_config {
    header_behavior = "<behavior>"
    # Include headers block only when behavior == "whitelist" AND items non-empty
    headers {
      items = [<sorted quoted list>]
    }
  }

  query_strings_config {
    query_string_behavior = "<behavior>"
    # Include query_strings block only when behavior == "whitelist" AND items non-empty
    query_strings {
      items = [<sorted quoted list>]
    }
  }
}
```

Behavior mapping: same table as Step 3.

### Step 5 — Generate `aws_cloudfront_response_headers_policy` resources

For each entry `<hash>` in `response_headers_policies`:

```hcl
resource "aws_cloudfront_response_headers_policy" "policy_<hash>" {
  name = "cfcdn-rhp-<hash>"

  # ── CORS config (only if cors_config is non-null) ──
  cors_config {
    access_control_allow_credentials = <bool>
    access_control_allow_headers {
      items = [<sorted list>]
    }
    access_control_allow_methods {
      items = [<sorted list>]
    }
    access_control_allow_origins {
      items = [<sorted list>]
    }
    # Only include if cors_config.expose_headers is non-empty
    access_control_expose_headers {
      items = [<sorted list>]
    }
    access_control_max_age_sec    = <int>   # omit if null/0
    origin_override               = true
  }

  # ── Security headers (only if security_headers is non-null) ──
  security_headers_config {
    # Include only the sub-blocks that are present and non-null in the manifest

    content_security_policy {
      content_security_policy = "<value>"
      override                = true
    }

    content_type_options {
      override = true
    }

    frame_options {
      frame_option = "DENY"   # or "SAMEORIGIN"
      override     = true
    }

    referrer_policy {
      referrer_policy = "<value>"
      override        = true
    }

    strict_transport_security {
      access_control_max_age_sec = <int>
      include_subdomains         = <bool>
      preload                    = <bool>
      override                   = true
    }

    xss_protection {
      mode_block = true
      override   = true
      protection = true
    }
  }

  # ── Custom headers (only if custom_headers list is non-empty) ──
  custom_headers_config {
    items {
      header   = "<header-name>"
      override = <bool>
      value    = "<value>"
    }
    # one `items` block per entry
  }

  # ── Remove headers (only if remove_headers list is non-empty) ──
  remove_headers_config {
    items {
      header = "<header-name>"
    }
    # one `items` block per entry
  }

  # ── Server timing (only if server_timing_headers_config is non-null) ──
  server_timing_headers_config {
    enabled       = <bool>
    sampling_rate = <float>
  }
}
```

**Rules**:
- Omit any entire sub-block if its source field is null or empty list.
- Sort all `items` lists lexicographically.
- Do not emit comments from this template literally — they are instructions to you.

### Step 6 — Generate outputs block

After all resources, append an outputs section so domain modules can reference
the policies by Terraform resource address:

```hcl
# ============================================================
# Outputs — consumed by domain modules via terraform_remote_state
# or direct module composition
# ============================================================

output "cache_policy_ids" {
  description = "Map of hash → cache policy resource ID"
  value = {
    <for each cache policy hash>
    "<hash>" = aws_cloudfront_cache_policy.policy_<hash>.id,
    <end for>
  }
}

output "origin_request_policy_ids" {
  description = "Map of hash → origin request policy resource ID"
  value = {
    <for each ORP hash>
    "<hash>" = aws_cloudfront_origin_request_policy.policy_<hash>.id,
    <end for>
  }
}

output "response_headers_policy_ids" {
  description = "Map of hash → response headers policy resource ID"
  value = {
    <for each RHP hash>
    "<hash>" = aws_cloudfront_response_headers_policy.policy_<hash>.id,
    <end for>
  }
}
```

Use real hash values from the manifest — no template placeholders in the output.

### Step 8 — Self-validation

After writing, read the file back and verify:

1. Every resource block that was opened with `{` has a matching `}`.
2. No resource name contains characters other than `[a-z0-9_]`.
3. The `provider "aws"` block with `alias = "us_east_1"` is present exactly once.
4. No Terraform string contains unescaped `${}` from variable interpolation
   (only intentional `${var.xxx}` patterns are allowed; all policy values are
   literal strings).
5. The `outputs` block lists exactly as many entries as there are resources of
   each type.

If any check fails, report the specific failure and re-generate. Do not leave a
broken file on disk.
