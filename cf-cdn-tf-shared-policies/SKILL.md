# cf-cdn-tf-shared-policies

Generates `cloudflare-to-aws-cdn/terraform/shared/policies.tf` from the
deduplicated policy manifest. This file must be written **before** any domain
`main.tf` is generated, because domain modules reference these policy resources
by Terraform ID.

---

## Path Resolution

All paths are relative to the current working directory when the skill is invoked.

| Logical name | Resolved path |
|---|---|
| Dedup manifest (input) | `cloudflare-to-aws-cdn/shared/dedup_manifest.json` |
| Output file | `cloudflare-to-aws-cdn/terraform/shared/policies.tf` |

---

## Output Directory

```
cloudflare-to-aws-cdn/terraform/shared/
  policies.tf          ← generated by this skill (includes outputs block)
```

Create the directory if it does not exist. Only write `policies.tf`.

## Workflow

### Step 0 — Verify input exists

Before generating any code, verify the dedup manifest exists:

```
cloudflare-to-aws-cdn/shared/dedup_manifest.json
```

If the file is missing, halt and report the missing path; do not proceed.

The manifest structure is fully documented in Step 1 below with a complete
JSON example covering all three policy types.

---

### Step 1 — Parse `dedup_manifest.json`

The manifest produced by `cdn-finalize.py` has this top-level structure:

```jsonc
{
  "generated_at": "<ISO 8601 timestamp>",
  "total_policies": 5,
  "policies": {
    "policy-a3f7b291": {
      "hash": "<full sha256 hex>",
      "type": "cache_policy",
      "count": 3,
      "sample_hostname": "cdn.example.com",
      "config": {
        "bypass": false,
        "ttl": { "min": 0, "default": 300, "max": 3600 },
        "cache_key": {
          "headers": [],
          "cookies": ["session"],
          "query_strings": "none"
        },
        "enable_gzip": true,
        "enable_brotli": true
      }
    },
    "policy-99abc123": {
      "hash": "<full sha256 hex>",
      "type": "origin_request_policy",
      "count": 2,
      "sample_hostname": "api.example.com",
      "config": {
        "forward": {
          "headers": "whitelist",
          "headers_list": ["Accept"],
          "cookies": "none",
          "cookies_list": [],
          "query_strings": "all"
        }
      }
    },
    "policy-cc112233": {
      "hash": "<full sha256 hex>",
      "type": "response_headers_policy",
      "count": 1,
      "sample_hostname": "www.example.com",
      "config": {
        "security_headers": {
          "strict_transport_security": { "enabled": true, "max_age": 31536000, "include_subdomains": true, "preload": false },
          "x_frame_options": "DENY",
          "x_content_type_options": true
        },
        "custom_headers": [],
        "cors": null
      }
    }
  }
}
```

Iterate over `manifest.policies`. For each entry, read `type` to determine which
Terraform resource to generate:
- `"cache_policy"` → `aws_cloudfront_cache_policy`
- `"origin_request_policy"` → `aws_cloudfront_origin_request_policy`
- `"response_headers_policy"` → `aws_cloudfront_response_headers_policy`

The `config` object contains the policy-specific fields. Use `policy_id` (the key,
e.g. `"policy-a3f7b291"`) as the Terraform resource name suffix.

If `manifest.policies` is absent or empty, write an empty `policies.tf` with only
the file header and a comment: `# No shared policies — all domains use AWS managed policies.`

### Step 3 — Generate `aws_cloudfront_cache_policy` resources

For each entry in `manifest.policies` where `type == "cache_policy"`, use
`policy_id` as the resource name suffix and read fields from `config`:

**3a. Bypass policy** (`config.bypass: true` OR `config.ttl.default == 0 AND config.ttl.max == 0`):

```hcl
resource "aws_cloudfront_cache_policy" "policy_bypass_<policy_id>" {
  name        = "cfcdn-cache-bypass-<policy_id>"
  min_ttl     = 0
  default_ttl = 0
  max_ttl     = 0

  parameters_in_cache_key_and_forwarded_to_origin {
    cookies_config {
      cookie_behavior = "none"
    }
    headers_config {
      header_behavior = "none"
    }
    query_strings_config {
      query_string_behavior = "none"
    }
  }
}
```

**3b. Normal cache policy** (`config.bypass: false`):

```hcl
resource "aws_cloudfront_cache_policy" "policy_<policy_id>" {
  name        = "cfcdn-cache-policy-<policy_id>"
  min_ttl     = <config.ttl.min>
  default_ttl = <config.ttl.default>
  max_ttl     = <config.ttl.max>

  parameters_in_cache_key_and_forwarded_to_origin {
    cookies_config {
      cookie_behavior = "<behavior>"
      # Include cookies block ONLY when behavior is "whitelist" or "allExcept" AND items non-empty
      cookies {
        items = [<quoted, comma-separated items>]
      }
    }
    headers_config {
      header_behavior = "<behavior>"
      # Include headers block ONLY when behavior is "whitelist" AND items non-empty
      headers {
        items = [<quoted, comma-separated items>]
      }
    }
    query_strings_config {
      query_string_behavior = "<behavior>"
      # Include query_strings block ONLY when behavior is "whitelist" or "allExcept" AND items non-empty
      query_strings {
        items = [<quoted, comma-separated items>]
      }
    }
    enable_accept_encoding_brotli = <true|false>   # from config.enable_brotli; default true
    enable_accept_encoding_gzip   = <true|false>   # from config.enable_gzip; default true
    # Note: cache behavior compress=true is always set by cf-cdn-tf-domain (not in cache policy)
  }
}
```

**Cache key field mapping** from `config.cache_key`:

| IR field | Terraform behavior | Terraform items |
|----------|-------------------|-----------------|
| `config.cache_key.headers` (always a list) | empty list → `"none"` (omit `headers {}` block); non-empty list → `"whitelist"` | `items = [<sorted list>]` |
| `config.cache_key.cookies` (always a list) | empty list → `"none"` (omit `cookies {}` block); non-empty list → `"whitelist"` | `items = [<sorted list>]` |
| `config.cache_key.query_strings` | string `"none"` → `"none"` (omit `query_strings {}` block); string `"all"` → `"all"` (omit `query_strings {}` block); list → `"whitelist"` | `items = [<sorted list>]` |

**Valid behaviors per config type (cache policy only):**

| Config | `none` | `whitelist` | `allExcept` | `all` |
|--------|--------|-------------|-------------|-------|
| `cookies_config` | ✅ (no items block) | ✅ (items required, non-empty) | ✅ (items required, non-empty) | ✅ (no items block) |
| `headers_config` | ✅ (no items block) | ✅ (items required, non-empty) | ❌ NOT VALID | ❌ NOT VALID |
| `query_strings_config` | ✅ (no items block) | ✅ (items required, non-empty) | ✅ (items required, non-empty) | ✅ (no items block) |

**Critical rules:**
- Include the items sub-block (`cookies {}`, `headers {}`, `query_strings {}`) ONLY when behavior is `"whitelist"` or `"allExcept"` AND items is non-empty.
- Omit the items sub-block entirely when behavior is `"none"` or `"all"`.
- `whitelist` or `allExcept` with an empty items list is an API error — if the IR has an empty list, fall back to `"none"` and add a `# WARNING: empty whitelist converted to none` comment.

**Item list formatting**: always emit as a Terraform list literal with double-quoted
strings, sorted lexicographically. Example: `items = ["foo", "bar", "baz"]` →
after sort: `items = ["bar", "baz", "foo"]`.

### Step 4 — Generate `aws_cloudfront_origin_request_policy` resources

For each entry in `manifest.policies` where `type == "origin_request_policy"`:

```hcl
resource "aws_cloudfront_origin_request_policy" "policy_<policy_id>" {
  name = "cfcdn-orp-<policy_id>"

  cookies_config {
    cookie_behavior = "<config.forward.cookies>"
    # Include cookies block when behavior == "whitelist" or "allExcept" AND cookies_list non-empty
    cookies {
      items = [<sorted quoted list from config.forward.cookies_list>]
    }
  }

  headers_config {
    header_behavior = "<config.forward.headers>"
    # Valid: none | whitelist | allViewer | allViewerAndWhitelistCloudFront | allExcept
    # Include headers block when behavior requires a list AND headers_list non-empty
    headers {
      items = [<sorted quoted list from config.forward.headers_list>]
    }
  }

  query_strings_config {
    query_string_behavior = "<config.forward.query_strings>"
    # Include query_strings block when behavior == "whitelist" or "allExcept" AND query_strings_list non-empty
    query_strings {
      items = [<sorted quoted list from config.forward.query_strings_list>]
    }
  }
}
```

Behavior mapping: same table as Step 3 **except** Origin Request Policy `header_behavior` supports the full set: `none`, `whitelist`, `allViewer`, `allViewerAndWhitelistCloudFront`, `allExcept`. All three fields (headers, cookies, query strings) support `allExcept` in ORP.

---

### Step 5 — Generate `aws_cloudfront_response_headers_policy` resources

For each entry in `manifest.policies` where `type == "response_headers_policy"`:

```hcl
resource "aws_cloudfront_response_headers_policy" "policy_<policy_id>" {
  name = "cfcdn-rhp-<policy_id>"

  # ── CORS config (only if cors_config is non-null) ──
  cors_config {
    access_control_allow_credentials = <bool>
    access_control_allow_headers {
      items = [<sorted list>]
    }
    access_control_allow_methods {
      items = [<sorted list>]
    }
    access_control_allow_origins {
      items = [<sorted list>]
    }
    # Only include if cors_config.expose_headers is non-empty
    access_control_expose_headers {
      items = [<sorted list>]
    }
    access_control_max_age_sec    = <int>   # omit if null/0
    origin_override               = true
  }

  # ── Security headers (only if security_headers is non-null) ──
  security_headers_config {
    # Include only the sub-blocks that are present and non-null in the manifest

    content_security_policy {
      content_security_policy = "<value>"
      override                = true
    }

    content_type_options {
      override = true
    }

    frame_options {
      frame_option = "DENY"   # or "SAMEORIGIN"
      override     = true
    }

    referrer_policy {
      referrer_policy = "<value>"
      override        = true
    }

    strict_transport_security {
      access_control_max_age_sec = <int>
      include_subdomains         = <bool>
      preload                    = <bool>
      override                   = true
    }

    xss_protection {
      mode_block = true
      override   = true
      protection = true
    }
  }

  # ── Custom headers (only if custom_headers list is non-empty) ──
  custom_headers_config {
    items {
      header   = "<header-name>"
      override = <bool>
      value    = "<value>"
    }
    # one `items` block per entry
  }

  # ── Remove headers (only if remove_headers list is non-empty) ──
  remove_headers_config {
    items {
      header = "<header-name>"
    }
    # one `items` block per entry
  }
}
```

**Rules**:
- Omit any entire sub-block if its source field is null or empty list.
- Sort all `items` lists lexicographically.
- Do not emit comments from this template literally — they are instructions to you.

### Step 6 — Generate outputs block

After all resources, append an outputs section so domain modules can reference
the policies by Terraform resource address:

```hcl
# ============================================================
# Outputs — consumed by domain modules via terraform_remote_state
# or direct module composition
# ============================================================

output "cache_policy_ids" {
  description = "Map of policy_id → cache policy resource ID"
  value = {
    <for each cache policy entry in manifest.policies>
    # If config.bypass == true:
    #   "<policy_id>" = aws_cloudfront_cache_policy.policy_bypass_<policy_id>.id
    # If config.bypass == false:
    #   "<policy_id>" = aws_cloudfront_cache_policy.policy_<policy_id>.id
    <end for>
  }
}

output "origin_request_policy_ids" {
  description = "Map of policy_id → origin request policy resource ID"
  value = {
    <for each ORP entry in manifest.policies>
    "<policy_id>" = aws_cloudfront_origin_request_policy.policy_<policy_id>.id,
    <end for>
  }
}

output "response_headers_policy_ids" {
  description = "Map of policy_id → response headers policy resource ID"
  value = {
    <for each RHP entry in manifest.policies>
    "<policy_id>" = aws_cloudfront_response_headers_policy.policy_<policy_id>.id,
    <end for>
  }
}
```

Use real hash values from the manifest — no template placeholders in the output.

### Step 8 — Self-validation

After writing, read the file back and verify:

1. Every resource block that was opened with `{` has a matching `}`.
2. No resource name contains characters other than `[a-z0-9_]`.
3. No Terraform string contains unescaped `${}` from variable interpolation
   (only intentional `${var.xxx}` patterns are allowed; all policy values are
   literal strings).
4. The `outputs` block lists exactly as many entries as there are resources of
   each type.

If any check fails, report the specific failure and re-generate. Do not leave a
broken file on disk.

## Naming Convention (Critical — Do Not Change)

Domain modules (`cf-cdn-tf-domain`) look up shared policies by **name** using
`data` sources. The naming convention below is a contract between this skill and
`cf-cdn-tf-domain`. Changing these names will break all domain modules.

| Resource type | Name format |
|---------------|-------------|
| Cache policy (normal) | `cfcdn-cache-policy-<policy_id>` |
| Cache policy (bypass/no-cache) | `cfcdn-cache-bypass-<policy_id>` |
| Origin request policy | `cfcdn-orp-<policy_id>` |
| Response headers policy | `cfcdn-rhp-<policy_id>` |
